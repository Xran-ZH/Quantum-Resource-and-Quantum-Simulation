This directory preserves the original exploratory scripts, notebooks, figures,
and data used during the development of the project.

These files are kept for provenance. They may contain hard-coded paths,
exploratory cells, disabled data-generation blocks, or historical naming
conventions. The cleaned reproduction workflow will be documented separately
in the main README and in the future `reproduce/` directory.

The original data directories are archived under `data_original/`:

- `data_original/data/`
- `data_original/vardata/`
- `data_original/newdata/`
- `data_original/mag_time_data/`
- `data_original/LongtimeSim/`
- `data_original/OtherHamiltonians/`

The legacy notebooks are historical records and still contain their original
relative paths.
